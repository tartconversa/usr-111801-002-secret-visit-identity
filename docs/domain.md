# 景区资料语义

来源可以是主管部门、景区运营方或合作机构。每份原件有来源、字段说明与摘要，产品修订引用原件，交付时按领取方、用途和来源辖区核对许可。受理人员应能区别来源事实、内部编排和已交付凭据。

当前项目围绕暗访记录的身份与争议归属开展资料协作。正式公告、复核观察和运营材料各有发布主体；示例记录不代表真实景区状态。

## 景区主体与身份沿革

景区主体以编号登记，名称只是沿革中的一段记录：同一编号可经历更名，同名景区分属不同编号与辖区。合并与拆分都记为身份事件，载明来去主体、时间与理由；事件发生后原有主体停用，新材料只能归属到存续主体。

## 材料归属与对应

原件归属按主体编号而非名称登记，同时保留原件上的申报名称与归属依据（如名录编号），供事后核对；同名混淆经更正流程改派，旧版本保留。暗访观察与景区答复来自不同来源、各有版本，对应关系逐条建立：答复只能对应归属同一主体的观察，一份答复的新版本作为新原件另行对应，旧对应不覆盖。

## 争议与结论使用

景区只能对归属本主体的观察提出质疑，同一观察同时只受理一项未裁定质疑。评级摘要逐条记录观察的采用或排除及理由：无争议或质疑已驳回的观察列为已确认事实；争议未裁定或质疑成立的观察一律排除并注明原因。结论钉住所依据的归属版本与当时关联的答复，身份合并或拆分后仍可追溯：原来谁对哪条观察作了答复、历次结论为何采用或排除它。
